# Transit Tales

**Transit Tales** is the game title; **TransitTales** is the project identity for this collection of playful transit adventures. The local project folder remains **`D:\my_projects\Lego`**, and the Copilot app’s existing **Lego** registration is retained intentionally. The npm package is named **`transit-tales`** to follow npm’s lowercase naming rules. The GitHub repository is [micwu-personal/TransitTales](https://github.com/micwu-personal/TransitTales). The collection opens in an English / Chinese / Japanese / Cyrillic Mongolian / traditional Mongolian transit concourse connecting **Rush Hour Rescue / 地铁调度室**, **Escalator Orchestra / 扶梯拼拼乐**, **Beijing Journey / 北京出行记**, **Melody Train / 旋律列车**, **Universe Journey / 宇宙旅行** and **Little Economy / 小小经济家**, alongside the preserved original **Build a World** experiment.

Build a World is an original, browser-first 3D building game for children. Make miniature worlds from clay-like shapes, then watch each world respond to what you built. Built with TypeScript, Babylon.js, and Vite. No account, downloads, or external game assets are needed; creations are saved in this browser.

## Run

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the local address Vite prints (normally `http://localhost:5173`). `npm run build` makes a production site in `dist/`; `npx vite preview` serves that build. `npm run test` runs the building, transit, localization, and renderer-adapter tests. The original building game requires WebGL; the transit games offer genuine 3D presentation with complete lightweight 2D fallback, so transit gameplay does not require WebGL.

**Tuning is explicitly A4 = 440 Hz, twelve-tone equal temperament**, using `440 * 2 ** ((midi - 69) / 12)`.
